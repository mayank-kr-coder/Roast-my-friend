# RoastMyFriend 😂

A mobile-friendly, client-side Hinglish roast generator. No backend, login, API key, or payment needed.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, or Firefox.
3. Enter a name, choose a category, and tap **ROAST KARO!**

## Deploy free with GitHub Pages
1. Sign in to https://github.com/ and create a new **public** repository named `roastmyfriend`.
2. Upload `index.html` (and this README if you want).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait a few minutes. Your website URL should look like:
   `https://YOUR-USERNAME.github.io/roastmyfriend/`
7. Open the URL on your phone and test the buttons.

## Alternative: Netlify Drop
1. Visit https://app.netlify.com/drop
2. Sign in if prompted.
3. Drag the extracted folder (containing `index.html`) onto the page.
4. Netlify will publish a free preview URL.

## Features
- Random friendly Hinglish roasts across six categories
- Random roast score
- WhatsApp share, native share, copy roast and copy link
- Downloadable PNG roast card drawn in the browser
- Responsive mobile-first layout
- No user accounts and no server-side collection of entered names

## Notes
- Clipboard and native share features work best on HTTPS after deployment.
- This is a starter project. Before adding analytics, ads, accounts, or a custom domain, review the relevant privacy rules and platform policies.
- Keep jokes playful; don't use the tool for threats, harassment, or sharing private information.
